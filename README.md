# Canvas con JavaScript · Prototipo

Ejercicio de Canvas 2D con ajuste del tamaño de pantalla y renderizado de elementos mediante JavaScript.

## Alcance actual

`JavaScript/game.js` ajusta el canvas al tamaño de la ventana, calcula el tamaño de las celdas y dibuja una columna de emojis. `JavaScript/map.js` contiene material para el mapa.

El código actual es un prototipo de renderizado; no se presenta como un videojuego terminado.

## Uso

Abre `index.html` desde un servidor estático. Los estilos están en `style/`. Consulta `LICENSE` para las condiciones del código.
